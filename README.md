# V-Flow for Windows

V-Flow configures and commissions V-Flow monitors over RS-485. This repository holds the Windows installers only.

## Install

1. Open the [latest release](https://github.com/ggasson/vflow-releases/releases/latest) and download `V-Flow-Setup-<version>.exe`.
2. Run it. No administrator rights are needed: V-Flow installs for your Windows user only.
3. If Windows shows "Windows protected your PC", choose **More info**, then **Run anyway**.
4. Start V-Flow from the Start menu.

## Updates

V-Flow checks this page every time it starts, so the laptop must be online. When a newer version is available, V-Flow won't start until you install it. Choose **Open download page**, then run the new installer over the old one.
